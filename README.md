# 読書・日記メモ（個人用）

思ったことをそのまま書いて保存し、見出しの一覧から飛べるメモアプリ。PC・スマホ共通。
読書メモが主で、日記もついでに書ける。写真（本のページなど）とPDFも本文に添えて保存できる。
目的は「記憶して、AIに読ませやすくする」こと（要約・記事のネタ出しなど）。

- 入力: 種類（読書／日記）・書名（任意）・タイトル（空なら本文の1行目）・本文・写真/PDF
- 音声入力: スマホはキーボードのマイク、PCは Windowsキー＋H（アプリ側の機能ではない）
- 一覧: 新しい順。タイトルと本文の検索、読書／日記の絞り込み
- 写真は長辺1600pxのJPEGに縮めて保存。PDFはそのまま
- `ニュース収集アプリ`（`projects/news-app/`）とは別アプリ。同じSupabaseプロジェクト・同じログインを使う

## 保存先（`web/config.js`）
| モード | 条件 | 保存先 |
|---|---|---|
| お試し版 | `config.js` が空 | このブラウザの中だけ（他の端末とは共有されない） |
| クラウド版（今） | Supabaseの URL と anon key を入れる | Supabase（`memos` 表＋`memo-files` の非公開置き場。本人だけ読み書き可。`supabase/schema.sql`） |

## 手元で動かす
`start.bat` をダブルクリック → http://localhost:8766

## 秘密情報
- `web/config.js` に入れてよいのは anon key（公開前提のキー）だけ。service_role key は入れない
- 公開リポジトリに置くのはコードだけ。メモ本体と写真はSupabase側にあり、リポジトリには入らない
